# Solaris Dev Shop: project facts and media

Use these facts when describing the project. This page is a reusable source for
reviewers and directory editors; it does not prove that a listing is accepted.

## Description

**Short:** 61 portable specialist skills with an explainable deterministic task router.

**Expanded:** Solaris Dev Shop is an MIT-licensed library of 61 specialist skills
across 12 departments, plus a chief-of-staff skill and an optional Python intake
router. Search for a skill, route a bounded request, and open the selected skill
in your own agent. The router needs no model key and performs no specialist work.

## Claims to avoid

Do not describe this as 61 running agents, an autonomous employee service, a
hosted marketplace, a model benchmark, or a guarantee of production readiness.
The skills run only when invoked in a compatible host with the necessary tools.
There are no provider credentials in the router and no automatic deploy or send.

A routing confidence score is relative keyword evidence. A directory's health
score is that directory's metric. Structural checks, downloads, clones and stars
do not establish task success, human adoption or customer outcomes.

Use “listed” for a proven listing. Use “featured” only when that publisher has
actually used it. Pending verification backlinks and generic application badges
are not accepted listings. Preserve each publisher's badge and brand guidance.
