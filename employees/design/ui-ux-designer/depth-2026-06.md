# UI/UX Designer - Depth pass 2026-06-13 (methodology only, no code bundled)

## 1. Official Figma Dev Mode MCP server (promote to primary design-to-code path)
Figma now ships a FIRST-PARTY Dev Mode MCP server (launched mid-2025). It gives the agent precise design-system context directly: the selected layer, node tree, variant information, layout constraints, DESIGN TOKENS/variables, components, and asset references - and as of March 2026 it is BIDIRECTIONAL (push a rendered UI from VS Code back into Figma as editable frames).

Re-tiering vs the existing community MCP:
- PRIMARY (design-to-code): the OFFICIAL Figma Dev Mode MCP. It is variables/tokens-aware, which dovetails with this employee's token pipeline (it reads the same Figma variables Tokens Studio exports). Setup: Figma desktop -> Preferences -> Enable local MCP Server, switch to Dev Mode; point a coding agent/Cursor/VS Code at it.
- FALLBACK / OSS: GLips/Figma-Context-MCP (figma-developer-mcp, MIT, ~14.3k stars) - the community frame-to-code path (link not screenshot), useful when an MIT/self-hosted server is required or for a Figma file you can only reach via PAT.
- Both are design-to-code accelerators, NOT the token source of truth: Tokens Studio -> Style Dictionary still owns tokens. Generated code still passes the token hierarchy (primitive->semantic->component) + WCAG 2.1/2.2 AA QA. (Updates references/figma-context-codegen.md.)

## 2. Small-task lane
- ONE component from a Figma frame: official Figma Dev Mode MCP on the selected node -> generate -> map to semantic tokens -> WCAG pass. Skip the full design-system workflow.
- ONE style/palette/font decision: query the design-intelligence DB (search.py --domain) - never freestyle.
- FULL design system: the existing 8-step new-design-system workflow + token pipeline.

## 3. Execution path (what is wired vs plan-only)
- WIRED when host connects: the official Figma Dev Mode MCP (host runs Figma desktop + enables the local MCP server) OR GLips figma-developer-mcp (host runs it with a Figma PAT). Either feeds frame/token context to the agent.
- WIRED local (zero-dep): the design-intelligence DB query (Python 3, no deps) - search.py for style/palette/typography/UX/chart/stack decisions.
- VERIFICATION gate: every delivered UI passes the priority checklist 1->10 (accessibility + touch are CRITICAL ship-blockers), runs through the token system (no raw hex/px), and is checked for contrast 4.5:1 / focus rings / 44-48px targets.
- PLAN-ONLY: with no Figma MCP connected, work from provided specs/links; never claim a frame was implemented from pixels alone - request the Figma link + use the MCP.
