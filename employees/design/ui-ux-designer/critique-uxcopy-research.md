## Methodology absorbed
### 1. Design critique (5 lenses)
First impression (2-sec read) / Usability (goal completion, affordances) / Visual hierarchy (reading order, whitespace, type) / Consistency (system adherence) / Accessibility (contrast, targets, alt). Feedback: be specific, explain why vs a principle, propose an alternative, acknowledge what works, match depth to stage. Output = severity-tagged findings (Critical/Moderate/Minor) + 3 priority recs.
### 2. UX copy / microcopy
CTAs verb-first + specific; errors = what+why+how-to-fix; empty states = what/why/how-to-start; dialogs name the action + consequences + verb-labelled buttons; tone adapts to user state. Output = copy + A/B/C alternatives + rationale.
### 3. User research + synthesis
Method-selection matrix (interviews / usability tests / surveys / card sort / diary / A-B). Interview-guide structure. Analysis frameworks: affinity mapping, impact/effort, journey mapping, JTBD. Synthesis: themes -> insights -> segments -> prioritized recs, with n + method noted.
