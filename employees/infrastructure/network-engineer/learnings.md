- **2026-06-14 - Design lesson**: the most defensible single security upgrade for a home/office network is VLAN segmentation WITH firewall rules - VLANs alone are not security because inter-VLAN routing is open by default. Rule ordering (allow Pi-hole:53 before the RFC1918 block) is the subtle gotcha that breaks DNS for IoT if reversed.

Revisit once the actual machine inventory (build agents, console dev kits, NAS count) is known.
- **2026-06-14 - Boundary lesson**: the four-way split (network vs devops vs cloud vs sre vs iot) keeps this employee from drifting into pipeline/cloud/reliability/firmware work. Network Engineer owns the packets and the topology; it supplies evidence to SRE during incidents and a VLAN to IoT, but does not run the pager or write firmware.

- **2026-10-18 - Offline diagnosis (G10)**: added `netdiag.py` + `offline-trace-diagnosis.md`. Lessons: a stopped traceroute is not a route fault when TCP or TLS answered (ICMP filtering); a certificate name mismatch is also a DNS question unless the expected address is known; certificate dates must be judged at capture time, not now; a layer with no evidence stays a candidate instead of being assumed fine.
- **2026-10-18 - G10 rework (reviewer finding on 3ebbe73)**: `DNS:`-prefixed SAN entries were cut by 3 characters (the prefix is 4), so a correct certificate was reported as TLS_NAME_MISMATCH. Lesson: parse typed entries with a real prefix match (case-insensitive, including openssl's `IP Address:`), compare addresses as addresses, and keep a regression test plus a clean mismatch control for every parser fix.
- **2026-10-18 - G10 r3 (M10 Grok self-validation on 6af7849)**: keytool, Windows and one-line SAN spellings gave false mismatches; `*.com`/`*.co.uk` wildcards counted as covering; non-ASCII names were case-folded; an SNI different from the target went unflagged; deep JSON crashed; `fromisoformat` accepted different times on 3.9 and 3.11. Lesson: accept every common spelling explicitly, note what is not understood instead of judging it, never fold Unicode, parse times with one strict RFC 3339 rule, and make the oracle kill each reviewer mutant.
- **2026-10-18 - G10 r4 (M10 r2 Grok self-validation on be36f86)**: treating every unused SAN type as "not understood" let one URI or email entry hide a real name mismatch; the strict time rule refused valid 7 to 9 digit fractions; the oracle's wildcard-depth case had become a suffix-rule case. Lesson: separate "known but irrelevant" from "not understood", follow the RFC's full grammar when calling a parser strict, and recheck each oracle case still isolates the rule it names after a related fix.
- **2026-10-18 - G10 r5 (M10 r3 Grok self-validation on 69c6081)**: keytool `URIName:`, `OIDName:`, `Other-Name:` and certutil `URL=` were missing from the non-host list, so a URI still hid a real mismatch, and the note advised pasting it as DNS; splitting a typed list only before type prefixes glued a bare name to the entry before it (`DNS:a, api.example`). Lesson: one shared type list feeds both the type test and the split; after the split, split host and bare pieces at their own commas, never non-host values; a hint must never invent a host name.
- **2026-10-18 - G10 r6 (M10 r4 V1)**: keeping a non-host SAN value whole so a DirName keeps its commas also swallowed a bare host name pasted after a URI on the same line, giving a confident wrong mismatch. Split a non-host value at ", " only when the next chunk has no "=" and no type prefix; test each split rule with a covering name placed after every entry type, not only after DNS.
