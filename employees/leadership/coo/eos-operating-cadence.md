# EOS / Traction operating cadence (execution-depth, 2026-06-15)
Methodology-only (bradfeld/ceos, MIT; Traction by Wickman). The operating CADENCE the advisory frameworks lacked. Raises ops success rate by making execution rhythmic + measurable.

## The cadence
- ROCKS: 3-7 quarterly priorities per person/company; everything else is noise. Reviewed weekly.
- WEEKLY L10 (Level 10) meeting agenda (90 min, same time): Segue (5) -> Scorecard review (5) -> Rock review (5) -> Customer/employee headlines (5) -> To-do list (5) -> IDS (60) -> Conclude (5, rate the meeting 1-10).
- SCORECARD: 5-15 weekly leading measurables with an owner + a goal; green/red at a glance; drives the meeting, not feelings.
- IDS (Identify-Discuss-Solve): the issue-resolution loop - identify the REAL issue (not symptom), discuss once, solve with an owned action. Don't re-litigate solved issues.
- ACCOUNTABILITY CHART: seats/roles (not people) with 5 key responsibilities each; one owner per seat; clarifies who-owns-what.
- PROCESS (FBA - Followed By All): document the 20% of steps that drive 80% of the result per core process; score followability; the COO owns process consistency.
- ORGANIZATIONAL CHECKUP: periodic health score against the components.

## Use
Install the L10 + Scorecard + Rocks rhythm for an ops engagement; resolve issues via IDS; map seats via the Accountability Chart; codify core processes FBA. This is the executable spine under the advisory frameworks.
