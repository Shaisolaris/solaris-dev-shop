# Engineering Design (CAD) - Depth pass 2026-06-13 (methodology only, no code bundled)

## 1. KiCad re-tier: mixelpixx for deep PCB, lamaalrajih for light work
Verified: lamaalrajih/kicad-mcp (~468 stars, MIT) is a BASIC server - read-only Resources + simple BOM/netlist/DRC. mixelpixx/KiCAD-MCP-Server (~1,157 stars, MIT) exposes 122 tools across board/component/export/DRC/schematic/library/routing/AUTOROUTE, with JLCPCB and Freerouting integration.
- Routing rule: simple board read / BOM / netlist / DRC check -> lamaalrajih (lightweight). Real PCB design - placement, routing/autoroute, fab export, JLCPCB -> mixelpixx.
- Both MIT, both CONNECT (host runs KiCad 9+ and the chosen MCP server). Pin a known-good version; re-scan on upgrade.

## 2. Code-CAD lane added: build123d / CadQuery (Apache-2.0)
FreeCAD MCP drives the GUI feature tree. A complementary path is code-CAD: build123d (gumyr) and CadQuery - Python parametric BREP frameworks on the OCCT kernel (the same kernel FreeCAD uses).
- When to use code-CAD: parametric parts that should be diffable / version-controlled / generated from a script or data (parameter sweeps, families of parts, CI-generated geometry). Output STEP/STL like FreeCAD.
- When to use FreeCAD MCP: interactive modeling, the parts library, FEM (CalculiX), assemblies, and when a feature tree the host can open in the GUI is wanted.
- Both are legitimate; pick by whether the source of truth should be a script (code-CAD) or a GUI document (FreeCAD). No code bundled; these are self-host Python libs / a methodology, not absorbed code.

## 3. Small-task / prototype lane
- ONE simple printable primitive (spacer, bracket blank): FreeCAD execute_code one part -> STL. Skip FEM, skip assembly.
- PARAMETRIC FAMILY (e.g., a range of mounts): code-CAD (build123d) with a parameter loop -> batch STEP/STL.
- FULL manufacturable part: the Workflow 1-4 discipline (method -> tolerances -> parametric build -> read-back -> FEM if load-bearing -> export contract).

## 4. Rendering / execution path (what is wired vs plan-only) - heavily execution-dependent
- WIRED only when host starts the server: FreeCAD MCP (host runs FreeCAD + the addon RPC server) and a KiCad MCP (lamaalrajih or mixelpixx; host runs KiCad 9+, KICAD_SEARCH_PATHS set).
- PLAN-ONLY otherwise: with no server running, this employee PLANS the model and hands the host the connect steps - it must never claim a model exists in FreeCAD that it did not drive (read back via get_view/get_object before claiming success).
- PLAN-ONLY for code-CAD: build123d/CadQuery run as local Python (host installs); no MCP - the employee writes the script, host executes.
- HARDWARE reality: FEM is a CalculiX sanity check, NOT a certified analysis; physical fit/tolerance is only proven on a real print/machine.
