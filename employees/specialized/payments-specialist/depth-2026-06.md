# Payments Specialist - Depth pass 2026-06-13 (methodology only, no code bundled)

## 1. NET-NEW: Agentic Commerce Protocol (ACP) + Shared Payment Token (SPT)
The biggest 2026 development in this employee's exact domain, previously absent. ACP is an open standard (Apache-2.0) co-developed by Stripe + OpenAI + Meta (since 2025-09) for how AI agents complete purchases on behalf of buyers. It powers ChatGPT Instant Checkout (Etsy, Shopify brands).

Core primitive - Shared Payment Token (SPT):
- The agent (e.g. ChatGPT) collects the buyer's payment selection and hands the MERCHANT a narrowly scoped token - scoped to a SPECIFIC merchant and a SPECIFIC cart total - WITHOUT exposing the buyer's raw payment credentials.
- The merchant charges that SPT through any compliant PSP and stays the merchant of record.
- Governance: real-time fraud screening, spending limits, allowed-merchant lists, category restrictions can be applied.

How it updates the existing bright line (the 3 agentic patterns now):
| Pattern | What it is | Toolchain |
|---------|-----------|-----------|
| A) Agent takes a payment OP (refund/cancel/invoice) on behalf of a user | dev/ops-side | @stripe/agent-toolkit + human-confirmation on writes (existing) |
| B) Selling AI by usage (bill end-users per token/call) | product billing | @stripe/token-meter + metered pricing (existing) |
| C) Agent-INITIATED buyer checkout (ChatGPT/agent buys for the user) | NEW buyer-side | ACP + Shared Payment Token; merchant charges SPT via PSP (NET-NEW) |

Critical: SPT is the agent-era replacement for "never let an agent touch buyer card data." Instead of routing buyer card data through an agent (forbidden), the agent passes an SPT - scoped, credential-free, amount+merchant-bound. This is the safe primitive that makes agent checkout possible without PCI scope creep.

## 2. When ACP/SPT applies to Solaris work
- A merchant client wants to be discoverable/buyable inside ChatGPT (Instant Checkout): implement the ACP merchant side - accept SPTs, charge via the existing PSP, keep merchant-of-record. (Shopify clients get this via Shopify's ACP support; cross-ref ecommerce-specialist.)
- A client building an AI shopping agent: use SPT issuance flow so the agent never holds raw buyer credentials.
- Apply governance (spend limits, allowed-merchant lists) for any autonomous-buying agent.
No code bundled; ACP is an open spec (Apache-2.0) + Stripe docs. This is methodology + CONNECT.
