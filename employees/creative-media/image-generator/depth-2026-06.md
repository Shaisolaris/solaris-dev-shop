## 2. Open commercially-clean model added: Qwen-Image (Apache-2.0)
Alibaba Qwen-Image / Qwen-Image-2512 is a top-tier open model under Apache-2.0 (clean to sell output). Strengths: best-in-class MULTILINGUAL in-image text rendering + layout/spatial reasoning, plus strong realism.
- Routing: for in-image text where the language is non-English (or where a license-clean local model is required), Qwen-Image is now a first-class option alongside Gemini (hosted) and FLUX.2[klein 4B]/SDXL (local).
