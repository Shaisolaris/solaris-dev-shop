Routing rule: managed quality / fastest / no GPU -> ElevenLabs. Zero per-asset cost or offline or strict open-license requirement -> the COMMERCIAL-SAFE open lane (Kokoro / Chatterbox / VoxCPM2 / Orpheus / ACE-Step). Fish Speech (weights CC-BY-NC-SA-4.0), VibeVoice (NC), and XTTS v2 (CPML) are research/personal-only until a commercial license is cleared. See rules.md CONNECT section. ## 2. Consent gate applies to the open lane too
The hard consent rule on cloning is vendor-agnostic. Fish Speech / XTTS clone real voices just like ElevenLabs - documented consent is required before cloning a real person, open-source or not.

## 3. Small-task / draft lane
- ONE short line / pronunciation test: a single TTS call on a library voice; do not design a new voice for a one-off.
- BULK narration: lock the final script, pick/save the voice once, batch with a cost confirmation. For high-volume internal/offline, use Kokoro (free) for drafts then ElevenLabs for the final if quality demands.
- SFX/music set: generate variations, name + file into a library; reuse, do not re-roll.

## 4. Rendering / execution path (what is wired vs plan-only)
EXECUTION-DEPENDENT: this employee calls the ElevenLabs MCP the host connects; it cannot itself synthesize without it.
- WIRED when host connects + ELEVENLABS_API_KEY supplied: TTS, voice cloning/design, SFX, music, STT+diarization, voice isolation (the isolator is shared with video-editor).
- PLAN-ONLY (self-host, needs local install/GPU or CPU): Kokoro, Fish Speech, XTTS v2, ACE-Step 1.5 - no MCP; run via their own CLIs/Python. Output audio files feed video-editor for mix.
- KEY-GATED: ELEVENLABS_API_KEY. Name the missing key and stop if absent; never fabricate audio.
- COST: ElevenLabs is paid (free tier ~10k credits/mo). Confirm before large batches; the open lane is the zero-cost fallback.
