# Positioning phase (discovery -> positioning -> PRD) - depth reference

METHODOLOGY absorption (2026-06-13). Source: github.com/deanpeters/Product-Manager-Skills (5,104 stars; license NOASSERTION = FLAG). Methodology only - the repo's shell scripts (find-a-skill.sh, build-*.sh) and Streamlit playground are NOT bundled; self-host upstream if the tooling is wanted. Gate-0 PASS (partial): the PM owned discovery (W2 OST/JTBD), PRD (W1), prioritization (W3), roadmap (W4), and metrics (W5) - but positioning appeared only obliquely (an input to the PRD, "competitive research feeds PRD positioning"). deanpeters' 6-phase model (Discover -> POSITION -> Prioritize -> Specify -> Validate -> Measure) makes positioning an explicit step with its own artifact. This adds that step.

## Where it fits
Between W2 (discovery: you now know the validated problem + JTBD + real alternatives) and W1 (PRD: what to build). Write the positioning statement BEFORE the PRD so the PRD's goals and non-goals inherit a sharp target + differentiation, not a vague "make it good".

## The positioning statement (one artifact, fill every slot)
> For [target customer] who [statement of need/opportunity], [product name] is a [product category] that [key benefit / compelling reason to buy]. Unlike [primary competitive alternative incl. the status quo], our product [primary differentiation].

Rules:
- **Target customer** must be a real segment from discovery, not "everyone".
- **Category** is the mental shelf the buyer puts you on - choosing it frames every comparison.
- **Primary alternative** must include manual workarounds + the status quo (people do not choose in a vacuum - this ties to rules.md "list competing alternatives including the status quo").
- **Differentiation** must be a TRUE, defensible difference the target actually values (validated, not aspirational).

## April Dunford lens (for harder positioning calls)
When the obvious category is crowded or wrong, work the 5 components in order: (1) competitive alternatives (what they'd do without you) -> (2) unique attributes you have that alternatives lack -> (3) the VALUE those attributes enable -> (4) the customers who care most about that value -> (5) the market category that makes your value obvious. Choose the category last, deliberately - the wrong category invites the wrong comparison.

## Output + handoff
- Deliverable: the filled positioning statement + the alternatives/differentiation table + the chosen category and why.
- Feeds: the PRD problem + non-goals (W1), the roadmap North Star framing (W4), and CMO/messaging (positioning is the PM's job; messaging execution is CMO's).
- Re-test positioning at each major roadmap revision and when a new competitor enters.
